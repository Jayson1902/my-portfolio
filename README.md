## 🚀 Tecnologie Utilizzate

* **Framework:** [Angular](https://angular.dev/) (Standalone Components, Signals, Reactive Architecture)
* **Linguaggio:** [TypeScript](https://www.typescriptlang.org/) (ES6+)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Utility-first CSS, Mobile-First Responsive Design)
* **Hosting & Cloud:** [Firebase Hosting](https://firebase.google.com/)
* **Test Runner:** Vitest

## ✨ Funzionalità Principali

* **Design Responsive & Moderno:** Ottimizzato per dispositivi mobile, tablet e desktop.
* **Architettura Modulare:** Suddivisione in componenti riutilizzabili (`hero`, `navbar`, `stack`, `projects`, `about`, `footer`).
* **Download Documenti:** Download diretto del CV aggiornato e visualizzazione dell'attestato ufficiale di formazione (500 ore, Regione Lazio).
* **Prestazioni e SEO:** Ottimizzato per tempi di caricamento rapidi e metadata per motori di ricerca e recruiter.

## 🛠️ Installazione e Avvio Locale

1. Clona la repository:
   ```bash
   git clone https://github.com/Jayson1902/my-portfolio.git
   cd my-portfolio
   ```

2. Installa le dipendenze:
   ```bash
   npm install
   ```

3. Avvia il server di sviluppo:
   ```bash
   npm start
   ```
   L'applicazione sarà visibile su `http://localhost:4200/`.
